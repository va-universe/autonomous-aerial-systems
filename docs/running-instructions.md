# Running Instructions

This document explains how to download, open and run the project in Unity.

## Requirements

 - Unity Hub
 - Unity Editor `6000.3.12f1`

## Installation

 1. Clone the repository or download it as a ZIP file on GitHub.
 2. If you downloaded a ZIP file, extract it.
 3. Install Unity Hub if it is not already installed.
 4. In Unity Hub, open the `Installs` tab and install Unity Editor `6000.3.12f1`.
 5. In Unity Hub, open the `Projects` tab and select `Add` then `Add project from disk`.
 6. Select the project folder.
 7. Open the project and wait for Unity to start up.

## Testing A Prototype

Open one of the following scenes located in `Assets/Scenes` and press `Play`.

| Scene | Prototype |
|---------|---------|
| `AerodynamicSurfaceScene` | Aerodynamic Surface Prototype |
| `WingCamberScene` | Wing Camber Prototype |
| `FlyByWireScene` | Fly-By-Wire Prototype (after hotfix) |
